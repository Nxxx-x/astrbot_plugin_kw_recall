# 消息撤回（QQ 官方机器人）

群消息命中 **关键词 / 号码 / 链接 / 二维码 / Emoji** 后，由机器人调用 QQ 官方接口撤回。

五类规则**默认全部开启**，装完即生效。所有开关和文案都在 **AstrBot 管理面板 → 插件 → 消息撤回 → 配置** 里改，保存后即时生效。插件不带 Web 页面，也**不注册任何聊天指令**。

## 目录结构

```text
astrbot_plugin_kw_recall/
├── main.py              # 插件主体
├── _conf_schema.json    # 配置项定义（决定管理面板里显示什么）
├── metadata.yaml        # 插件元数据
├── requirements.txt     # 依赖（opencv、regex，均可选）
└── README.md
```

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/Nxxx-x/astrbot_plugin_kw_recall.git
```

装完在管理面板「插件」页点重载。依赖会随插件自动安装，装不上也不影响除二维码外的功能。

## 配置

管理面板 → 插件 → 消息撤回 → 配置。5 组规则，每组「启用 + 提示文案」，另有 2 个提示相关项：

| 配置项 | 默认 | 说明 |
|---|---|---|
| 撤回后发送提示 `notify` | 开 | 关掉则只撤回不发言 |
| 提示时 @ 被撤回的人 `notify_at` | 开 | 不需要 @ 就关掉 |
| 关键词 `keyword.enabled` | 开 | 子串包含，不区分英文大小写 |
| 关键词列表 `keyword.list` | 空 | 多行文本，一行一个 |
| 号码 `number.enabled` | 开 | 5 位及以上连续数字 |
| 链接 `link.enabled` | 开 | 协议头、`www.`、常见域名后缀、裸 IP |
| 二维码 `qrcode.enabled` | 开 | 图片里能解码出二维码 |
| Emoji `emoji.enabled` | 开 | 😀 ❤️ 👍 这类 Unicode 字符 |

没有总开关，不想要哪一类就单独关掉哪一类。每组的 `reply` 留空表示这一类撤回后不发言——比如只想让关键词撤回时提示、号码撤回时静默。

## 判断规则

**关键词**：子串匹配，`加群` 命中「快来加群领福利」。最多 200 个词，每个最长 50 字。别设单个汉字，误撤率会很高。词表为空时不生效。

**号码**：正则 `\d{5,}`。

| 消息 | 结果 |
|---|---|
| `12345` / `123456456789` / `价格 88888 元` | 撤 |
| `123 45` / `123-45` | 不撤（被空格、符号断开） |
| `1234` | 不撤 |

**链接**：`https://example.com/a`、`www.abc.com`、`abc.com`、`hello@qq.com`、`192.168.1.1` 都算；`main.py`、`3.14`、`1.2.3` 不算。域名后缀表在 `main.py` 的 `LINK_RE` 里。

**二维码**：下载消息里的图片用 OpenCV 解码。一条消息最多看 4 张图，单张超 10MB 跳过，下载超时 8 秒。只有开关打开时才下载解码，平时零开销。

**Emoji**：只认 Unicode 字符，出现一个就撤，没有数量阈值。`👨‍👩‍👧`、`👍🏽`、`🇨🇳`、`1️⃣` 各算一个。

匹配顺序为关键词 → 链接 → 号码 → Emoji，二维码只在文本没命中时才去解码图片。

## QQ 自带表情和 @ 不参与判断

QQ 原生表情（小黄脸、超级表情）在官机里不是字符，适配器会转成 `[表情:捂脸]` 标签；@ 则是 `<qqbot-at-user id="openid" />` 或 `<@!openid>`。两者都会留在 `message_str` 里。

这类标签在匹配前统一剥掉，原因有两个：

- 让 `[表情:捂脸]` 不触发 Emoji 规则——它是 QQ 的表情，不是用户打的 emoji；
- 让标签里的内容不误伤：`[表情:笑哭]` 不会命中关键词「笑哭」，`@某人` 的 openid 也不会被号码规则当成电话号。

`@小明 我的号 88888` 仍按真号码撤，但 `@小明 你好` 不会有任何动作。

## 前提条件

1. 机器人必须是**群管理员**，否则撤成员的消息返回 `40062003`；
2. 消息发出后 **2 分钟内**才能撤，超时返回 `40064004`；
3. 群主要放开「**接收全量消息**」，否则机器人只看得到 @ 它的消息。

群主和管理员自己发的消息不会被撤回，避免得罪人，也避免无权限报错。

## 依赖

- `opencv-python-headless`：二维码识别，约 50MB；
- `regex`：Emoji 计数，约 300KB。没装时退回内置 Unicode 区段匹配，个别组合表情会多算，但不影响开关。

两个都是可选的，缺失时只影响对应那一类，并在日志里提示一次。

## 已知限制

- 图片形式的贴纸、GIF 表情包不是字符，Emoji 规则抓不到；
- 群消息撤回没有官方 SDK 封装，直接发 `DELETE /v2/groups/{group_openid}/messages/{message_id}`。
