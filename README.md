# 消息撤回 · QQ 官方机器人

给 AstrBot 的 QQ 官方机器人（`qq_official` / `qq_official_webhook`）加一层「自动撤回」：群消息命中 **关键词 / 号码 / 链接 / 二维码 / Emoji** 就调用官方接口撤回，并可选发一条提示。

零聊天指令、零 Web 页面，五类规则**默认全部开启**，装完即生效，所有设置都在 AstrBot 管理面板里。

| | |
|---|---|
| 支持平台 | `qq_official`、`qq_official_webhook` |
| AstrBot 版本 | `>= 4.16,< 5` |
| 当前版本 | 1.8.0 |
| 依赖 | `opencv-python-headless`、`regex`（均可选，缺失只影响对应功能） |
| 许可 | MIT |

## 为什么需要它

QQ 官机的群消息撤回有几个绕不开的限制：接口没被 SDK 封装、只能撤 2 分钟内的消息、必须机器人是群管理员。这个插件把这些细节收在一处：命中规则就发 `DELETE /v2/groups/{group_openid}/messages/{message_id}`，失败按错误码分级记日志，不会因为一条漏撤刷满控制台。

常见的用法是拦广告——「加群」「代刷」这类关键词、一串手机号、一条外链、一张拉群二维码、一段刷屏 emoji，都在群规之外自动清掉。

## 五类规则

| 规则 | 判定方式 | 默认 | 典型命中 |
|---|---|---|---|
| 关键词 | 子串包含，不区分大小写，最多 200 词 | 开 | `加群` 命中「快来加群领福利」 |
| 号码 | 连续 5 位及以上数字 | 开 | `13800138000`、`价格 88888 元` |
| 链接 | 协议头、`www.`、常见域名后缀、裸 IP | 开 | `https://x.com/a`、`abc.cn`、`192.168.1.1` |
| 二维码 | 下载图片用 OpenCV 解码，读出内容即撤 | 开 | 拉群码、收款码截图 |
| Emoji | 出现任意 Unicode emoji 就撤，无数量阈值 | 开 | 😀 ❤️ 👍 `1️⃣` |

匹配顺序为 **关键词 → 链接 → 号码 → Emoji**；文本没命中时才去解码图片。一条消息只按第一个命中的规则处理，提示文案也取那一类的。

## 安装

**方式一：插件市场**（推荐）

AstrBot 管理面板 → 插件市场 → 搜索「消息撤回」→ 安装。

**方式二：手动放目录**

```bash
cd AstrBot/data/plugins
git clone https://github.com/Nxxx-x/astrbot_plugin_kw_recall.git
```

**方式三：上传 zip**

把 `astrbot_plugin_kw_recall.zip` 解压到 `AstrBot/data/plugins/`。

> 覆盖安装前先删掉旧的 `astrbot_plugin_kw_recall` 目录，避免旧版本残留文件（如老版本的 `views/`）一起被加载。

装完在「插件」页点重载。依赖会随插件自动安装；装不上也不影响除二维码外的四类功能。

## 配置

管理面板 → 插件 → 消息撤回 → 配置，保存即生效。

| 配置项 | 默认 | 说明 |
|---|---|---|
| 撤回后发送提示 | 开 | 关掉则只撤回、不发言 |
| 提示时 @ 被撤回的人 | 开 | 不需要 @ 就关掉 |
| 关键词 · 启用 | 开 | 子串包含，不区分大小写 |
| 关键词 · 列表 | 空 | 多行文本，一行一个；词表为空时该规则不生效 |
| 号码 · 启用 | 开 | 连续 5 位及以上数字 |
| 链接 · 启用 | 开 | 协议头、`www.`、域名后缀、裸 IP |
| 二维码 · 启用 | 开 | 图片中能解码出二维码 |
| Emoji · 启用 | 开 | Unicode emoji，有一个就撤 |

每组还有一个「提示文案」，默认分别是：

- 关键词：`消息含有关键词，已撤回`
- 号码：`请勿发送号码，已撤回`
- 链接：`请勿发送链接，已撤回`
- 二维码：`请勿发送二维码，已撤回`
- Emoji：`请勿发送emoji，已撤回`

把某一类的文案**留空**，这一类就静默撤回、不发言——比如号码静默清掉，关键词才提示。

没有总开关，不想管哪一类就单独关掉这一类。

## 判定细节

**号码**：正则 `\d{5,}`，数字必须彼此紧邻。

| 消息 | 结果 |
|---|---|
| `12345`、`123456456789`、`价格 88888 元` | 撤 |
| `123 45`、`123-45` | 不撤（被空格、符号断开） |
| `1234` | 不撤 |

**链接**：`https://example.com/a`、`www.abc.com`、`abc.com`、`hello@qq.com`、`192.168.1.1` 都算；`main.py`、`3.14`、`1.2.3` 不算。后缀表在 `main.py` 的 `LINK_RE`。

**二维码**：一条消息最多看 4 张图，单张超 10MB 跳过，下载超时 8 秒，解码超时 10 秒。同一张图只解码一次。

**Emoji**：只认 Unicode 字符，没有数量阈值。`👨‍👩‍👧`、`👍🏽`、`🇨🇳`、`1️⃣` 都算命中。

### QQ 自带表情和 @ 不参与判断

官机里 QQ 原生表情不是字符，适配器会转成 `[表情:捂脸]` 标签；@ 是 `<qqbot-at-user id="openid" />` 或 `<@!openid>`。两者都留在 `message_str` 里。

匹配前会统一剥掉，原因有两个：

- `[表情:捂脸]` 不该触发 Emoji 规则——那是 QQ 的表情，不是用户打的 emoji；
- 标签内容不该误伤：`[表情:笑哭]` 不会命中关键词「笑哭」，`@某人` 的 openid 也不会被当成号码。

所以 `@小明 我的号 88888` 照撤，`@小明 你好` 不动。

## 使用前提

1. 机器人必须是**群管理员**，否则撤成员消息返回 `40062003`；
2. 消息发出后 **2 分钟内**才能撤，超时返回 `40064004`；
3. 群主要放开「**接收全量消息**」，否则机器人只看得到 @ 它的消息，其余消息根本收不到。

群主和管理员自己发的消息不会被撤回——既避免得罪人，也避免无权限报错。

## 常见问题

**发了违规消息但没撤？**

按顺序排查：机器人是不是群管理员 → 消息是否已超 2 分钟 → 群是否开了「接收全量消息」→ 发消息的人是不是群主/管理员 → 对应规则是否开着、关键词是否在词表里。日志里搜 `[kw_recall]` 能看到命中原因或失败码。

**撤回了但没看到提示？**

确认「撤回后发送提示」是开的，并且这一类的提示文案不为空。

**提示里 @ 不出来，只是一段纯文本？**

官方文档对群消息 @ 的支持并不明确，部分账号/版本渲染不出蓝字 @。把「提示时 @ 被撤回的人」关掉即可，退回普通文本提示。

**二维码规则没反应？**

先看启动日志有没有 `未安装 opencv-python-headless`。装不上就关掉这一类，其余四类不受影响。二维码默认开启，如果群里图片量大、又不需要查码，建议关掉——每条带图消息都会先下载再解码。

**改了配置没生效？**

配置是保存到 `data/config/astrbot_plugin_kw_recall_config.json` 的。旧版本升级上来的配置文件会保留已有值，包括旧文案；想回到默认值，把那一项清空后保存，或在面板里删掉对应条目。

**会不会影响 AI 回复？**

不会。插件只是旁听群消息，命中才撤回，不阻断后续处理，也不注册任何指令，不会和别的插件的 `/xxx` 抢前缀。

**会不会撤回机器人自己的消息？**

不会。官机不把机器人自己发的消息推给机器人，撤回提示也不参与自己的规则判断。

**支持私聊或其他平台吗？**

只处理官机群消息。私聊、aiocqhttp、Telegram 等平台完全不介入。

## 实现与性能

群消息是高频路径，每条都要过一遍规则，所以做了几处收敛：

- **词表缓存**：关键词列表只在配置文本变化时重新解析，并预存小写形式，每条消息只 lower 一次正文；
- **Emoji 短路**：规则只关心「有没有」，命中第一个就返回，不做全量计数；
- **二维码缓存**：同一张图（按落盘文件名 / URL）只解码一次，最多记 256 条，超出按最久未用淘汰；
- **解码限流**：解码放线程池，最多 2 并发，单张限时 10 秒，不拖住事件循环；
- **日志分级**：超时 `40064004`、无权限 `40062003` 只写 debug，其他异常才 warning。

撤回用的是 botpy 的 `Route` + `DELETE`，botpy 新旧版本 `api._http` / `api.http` 两种挂载都做了兜底。
